# نظام المهام — TaskTrak

نظام مهام خفيف بين **المدير** و**مدراء الأقسام**: يُنشئ المدير المهام ويحدّد
تفاصيلها وأولويتها وجهتها، ويستعرضها مدير القسم ويضع تعقيبه عليها
(**تمت / قيد التنفيذ / لم تتم**) مع الملاحظات، مع نقاش لكل مهمة.

مبنيّ بـ **PHP 8.2 + MariaDB** بلا أي مكتبات خارجية، مُصمَّم للعمل على استضافة
cPanel المشتركة (مثل `tasktrak.co`).

## المزايا

- **دوران وأدوار**: حسابات حقيقية باسم مستخدم وكلمة مرور (تشفير bcrypt، جلسات آمنة، حماية CSRF).
  - **المدير**: إنشاء/تعديل/حذف المهام، إسنادها لمدير قسم، وإدارة المستخدمين.
  - **مدير القسم**: يرى المهام المسندة إليه أو لقسمه، ويضع تعقيبه وملاحظاته.
- **قاعدة بيانات مشتركة**: يعمل النظام بين عدة أشخاص على أجهزة مختلفة عبر الإنترنت.
- **تفاصيل المهمة**: عنوان، وصف، قسم، أولوية (عالية/متوسطة/منخفضة)، تاريخ استحقاق، ملاحظة المدير.
- **تعقيب مدير القسم**: حالة + ملاحظات، مع سجل وقت التعقيب.
- **نقاش المهمة**: تعليقات متبادلة بين المدير ومدير القسم.
- **لوحة إحصائيات** وتصفية حسب الحالة وبحث نصّي.
- واجهة عربية (RTL) متجاوبة.

## التشغيل محلياً (للتطوير)

يتطلب PHP ‏8.x و MariaDB/MySQL:

```bash
# 1) أنشئ قاعدة بيانات ومستخدماً، ثم:
cp app/config.sample.php app/config.local.php   # واملأ بيانات الاتصال

# 2) شغّل الخادم المدمج
php -S 127.0.0.1:8000

# 3) زُر المُثبِّت لإنشاء الجداول وحساب المدير
#    http://127.0.0.1:8000/install.php
```

بديلاً عن المُثبِّت، من الطرفية:

```bash
php bin/seed_user.php manager "اسم المدير" mudir "كلمة المرور"
```

## النشر على tasktrak.co

انظر [`deploy/README.md`](deploy/README.md) — سكربت `deploy/deploy-tasktrak.sh`
ينشر تلقائياً (رفع الملفات + إنشاء قاعدة البيانات عبر uapi + تهيئة حساب المدير).

## البنية

```
index.php            توجيه المسارات (front controller)
install.php          مُثبِّت لمرة واحدة
schema.sql           مخطط قاعدة البيانات (utf8mb4)
app/                 config · db · auth · helpers · models · bootstrap
views/               قوالب العرض
assets/              style.css · app.js
bin/seed_user.php    إنشاء مستخدم من سطر الأوامر
deploy/              سكربت ودليل النشر
```
