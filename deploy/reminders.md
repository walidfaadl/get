# تذكير المواعيد — القنوات والإعداد

يُرسل النظام تذكيراً **صباح يوم الموعد** لمن أنشأ الموعد ولمن شُورك معه، عبر ثلاث قنوات:

| القناة | الإعداد | الكلفة |
|---|---|---|
| **داخل النظام (الجرس)** | لا شيء — يعمل تلقائياً | مجاني |
| **تيليجرام** | توكن بوت + ربط المستخدم حسابه | مجاني |
| **واتساب** | حساب مزوّد + توكن (وقالب لـ Cloud API) | حسب المزوّد |

التشغيل الدوري يتم عبر **GitHub Actions** (`.github/workflows/reminders.yml`) كل صباح
(04:00 UTC = 07:00 الرياض)، أو عبر cron على cPanel:
```
0 7 * * *  /usr/local/bin/php /home/USER/tasktrak/bin/send_reminders.php >> reminders.log 2>&1
```
القناة «داخل النظام» تعمل فور الجدولة بلا أي إعداد إضافي.

## الأسرار على الخادم

تُضبط إمّا في `app/config.local.php`، أو — الأفضل — كـ **أسرار GitHub**
(`Settings → Secrets and variables → Actions`)، فيزرعها خطّ النشر تلقائياً في
`app/config.secret.php` على الخادم (لا يُرفع إلى Git).

### تيليجرام (موصى به — مجاني وسهل)
1. في تيليجرام، راسِل **@BotFather** ← `/newbot` ← اختر اسماً ومُعرّفاً (username).
2. انسخ **توكن البوت**، وأضِف الأسرار:
   - `TG_BOT_TOKEN` = التوكن
   - `TG_BOT_USERNAME` = مُعرّف البوت بلا `@`
   - `TG_WEBHOOK_SECRET` = نصّ عشوائي طويل (لتأمين الـ webhook)
3. بعد النشر، من صفحة «حسابي» (كمدير) اضغط **«ضبط webhook تيليجرام»** مرّة واحدة.
4. كل مستخدم يضغط **«ربط تيليجرام»** في «حسابي» ← **Start** في البوت → يُربط تلقائياً.

### واتساب
راجع المفاتيح في `app/config.sample.php`. اختر مزوّداً واحداً:
- **Cloud API** (رسمي، مجاني ضمن حدود): `WA_TOKEN` · `WA_FROM` (Phone Number ID) ·
  `WA_TEMPLATE` (قالب معتمد بمتغيّر `{{1}}`) · `WA_PROVIDER=cloud`.
- **UltraMsg** (الأسهل لربط رقمك): `WA_PROVIDER=ultramsg` · `WA_TOKEN` · `WA_FROM` (instance id).
- **Twilio**: `WA_PROVIDER=twilio` · `WA_SID` · `WA_TOKEN` · `WA_FROM` (رقم المُرسِل).

## ملاحظات
- كل مستخدم يتحكّم بقنواته من صفحة **«حسابي»** (رقم واتساب/ربط تيليجرام + تفعيل).
- لا يتكرّر الإرسال: جدول `appointment_reminders` يسجّل كل (موعد/مستخدم/قناة).
- جرّب فوراً: «حسابي» ← «إرسال رسالة تجريبية»، أو شغّل Workflow «Appointment reminders» يدوياً.
