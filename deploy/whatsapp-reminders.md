# تذكير المواعيد عبر واتساب — إعداد الخادم

يرسل النظام تذكيراً عبر واتساب **صباح يوم الموعد** لمن أنشأ الموعد ولمن شُورك معه،
شرط أن يكون كلٌّ منهم قد حفظ رقمه وفعّل التذكير من صفحة «حسابي».

الإرسال يتطلّب خطوتين على الخادم: **(1)** ضبط مزوّد واتساب، و**(2)** مهمة cron.

## 1) ضبط المزوّد في `app/config.local.php`

أضِف المفاتيح التالية (لا تُرفع إلى Git). اختر مزوّداً واحداً:

### أ) WhatsApp Cloud API — الرسمي (موصى به، مجاني ضمن حدود)
```php
'wa_enabled'  => true,
'wa_provider' => 'cloud',
'wa_token'    => 'EAAG...‹توكن دائم من Meta›',
'wa_from'     => '‹Phone Number ID من لوحة Meta›',
'wa_template' => 'appointment_reminder', // اسم قالب معتمد بمتغيّر واحد {{1}}
'wa_lang'     => 'ar',
```
> للرسائل المُبادَر بها (تذكير) **يلزم قالب معتمد** في Meta بمتغيّر واحد `{{1}}`
> يُوضع فيه نصّ التذكير. إن تركت `wa_template` فارغاً تُرسَل رسالة نصّية عادية
> (تعمل فقط ضمن نافذة 24 ساعة من آخر رسالة من العميل).

### ب) UltraMsg — الأسهل لربط رقمك مباشرة (اشتراك شهري)
```php
'wa_enabled'  => true,
'wa_provider' => 'ultramsg',
'wa_token'    => '‹token من لوحة UltraMsg›',
'wa_from'     => '‹instance id، مثل instance12345›',
```

### ج) Twilio for WhatsApp
```php
'wa_enabled'  => true,
'wa_provider' => 'twilio',
'wa_sid'      => '‹Account SID›',
'wa_token'    => '‹Auth Token›',
'wa_from'     => '+1415XXXXXXX', // رقم واتساب في Twilio
```

بعد الضبط: جرّب الإرسال من صفحة «حسابي» ← «إرسال رسالة تجريبية».

## 2) جدولة cron على cPanel

أضِف مهمة cron تعمل كل صباح (مثلاً 7 صباحاً). استبدل المسار بمسار مشروعك:
```
0 7 * * *  /usr/local/bin/php /home/USER/tasktrak/bin/send_reminders.php >> /home/USER/tasktrak/reminders.log 2>&1
```

- السكربت يختار مواعيد اليوم **المجدولة**، ويُرسل لكل مستلم مؤهّل مرة واحدة فقط
  (يمنع التكرار جدول `appointment_reminders`).
- إن لم يُضبط المزوّد، يخرج السكربت بأمان دون إرسال.
- رقم الهاتف يُحفظ بالصيغة الدولية بلا «+» (مثال: `9665XXXXXXXX`).
